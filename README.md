# Netflix Data Analysis & Power BI Dashboard

## Project Overview

This project analyzes the Netflix Titles dataset to understand content distribution, genres, countries, ratings, directors, and release trends.

The analysis was performed using Python for data analysis and Power BI for interactive data visualization.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Power BI
- GitHub

## Dataset

The dataset contains information about Netflix movies and TV shows, including:

- Title
- Content Type
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

## Analysis Performed

The project explores the following questions:

1. Movies vs TV Shows distribution
2. Year in which the most content was added to Netflix
3. Countries with the highest number of titles
4. Most common content ratings
5. Most popular genres
6. Dominant content type
7. Year with the highest number of movies released
8. Year with the highest number of TV shows released
9. Average release year of the content
10. Oldest content available in the dataset
11. Latest release year available in the dataset
12. Directors with the most content
13. Change in Netflix content over the years
14. Countries producing the most movies

## Power BI Dashboard

An interactive Power BI dashboard was created to visualize the analysis.

The dashboard includes visualizations for:

- Movies vs TV Shows
- Content distribution by country
- Popular genres
- Netflix content added by year
- Content ratings
- Content type distribution
- Content trends over time
- Average release year
- Top directors
